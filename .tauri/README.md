# Tauri updater signing keys

Boris signs release update artifacts with minisign keys generated by the Tauri CLI.

| File | Commit? | Purpose |
|------|---------|---------|
| `boris.key.pub` | Yes | Public key embedded in `desktop/src-tauri/tauri.conf.json` |
| `boris.key` | **Never** | Private key used only when building/signing releases |

## First-time / rotation

```bash
# From repo root (password optional but recommended for production)
cd desktop
bunx tauri signer generate -w ../.tauri/boris.key
```

Copy the public key string into `desktop/src-tauri/tauri.conf.json` →
`plugins.updater.pubkey`.

**If you lose the private key, existing installs cannot receive new signed updates
until users install a full rebuild that embeds a new public key.**

## Signing a release build

PowerShell:

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY_PATH = (Resolve-Path .\.tauri\boris.key).Path
# If the key has a password:
# $env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "..."

cd desktop
bun run tauri build
```

bash:

```bash
export TAURI_SIGNING_PRIVATE_KEY_PATH="$PWD/.tauri/boris.key"
# export TAURI_SIGNING_PRIVATE_KEY_PASSWORD="..."
cd desktop && bun run tauri build
```

Tauri writes updater artifacts next to the normal installers (e.g.
`Boris_*_x64-setup.exe` + `.sig` under `target/release/bundle/nsis/`).

## Publishing `latest.json` (GitHub Releases)

Attach to the **latest** release (same tag users should get):

1. Installer + signature (e.g. `Boris_1.0.1_x64-setup.exe`, `.sig`)
2. A static manifest named **`latest.json`**:

```json
{
  "version": "1.0.1",
  "notes": "Bug fixes and improvements.",
  "pub_date": "2026-08-12T00:00:00Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "<entire contents of the .sig file>",
      "url": "https://github.com/blocksdevpro/boris-assistant/releases/download/v1.0.1/Boris_1.0.1_x64-setup.exe"
    }
  }
}
```

The app polls:

`https://github.com/blocksdevpro/boris-assistant/releases/latest/download/latest.json`

## CI secrets

Store the private key as a GitHub Actions secret (never commit it):

- `TAURI_SIGNING_PRIVATE_KEY` — full file contents, or
- upload via `TAURI_SIGNING_PRIVATE_KEY_PATH` after writing the secret to a temp file
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — if the key is password-protected
