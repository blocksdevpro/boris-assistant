## Boris 1.2.0-beta.3

Third beta of Boris 1.2 for Windows x64. Stable installations remain on 1.1.0
unless you select the Beta update channel. NSIS installer only.

### Highlights

- A new presence orb shows listening, thinking, tool work, speaking, and input
  states across Home, the overlay, startup, and Teach Voice. Reduced-motion
  settings keep the orb static.
- Live transcription previews appear during voice capture when the speech
  model supports partial results. The overlay also shows current tool activity
  and progress notes.
- Streamed captions append without replaying earlier words. The overlay grows
  downward from a stable top edge, and late status updates cannot replace a
  newer engine state.
- Wake-word interruption now works during confirmation prompts and re-asks.
  Device changes restart the prompt on the new device, and confirmation rounds
  follow the agent's configured budget.
- Typed input can offer numbered choices alongside exact values, secrets, and
  large pastes. File tools suggest nearby names when a spoken path does not
  match. Long tool results can be reread without repeating the operation.
- Bundled playbooks cover code changes, debugging, explanations, design, code
  review, technical writing, mentoring, and skill creation.

### Reliability

- Trusted instructions are separated from memory, personal context, skill
  catalogs, and other untrusted data in model requests.
- Context compaction preserves recent unsummarized turns, accounts for the
  serialized request, and rejects oversized inputs before a provider call.
- OpenRouter streaming no longer duplicates text when a response contains both
  incremental and complete message content. Empty streams can fall back to a
  blocking response.
- Confirmation prompts use short, speakable descriptions. A bare "please"
  triggers a re-ask instead of approving an action.
- Voice and input cancellation preserve pending work correctly, and stale
  overlay captions and status transitions are cleared consistently.

### Install and update

1. Download `Boris_1.2.0-beta.3_x64-setup.exe` and run it over your existing Boris installation.
2. For future betas, select **Settings > General > Updates > Beta**.
3. On a first installation, finish model installation and add your OpenRouter API key in Settings.

This release retains beta.2's local memory store. When upgrading from beta.1 or
an older version, the one-time legacy-memory migration sends historical memory
to the LLM provider already configured for Boris. Original files are retired
only after refinement and verification succeed. Set `BORIS_MEMORY=0` before the
first launch to disable canonical memory and skip migration.

### Configuration and developer notes

- Freeform capture supports `BORIS_MAX_UTTERANCE_SECS` from 15 to 180 seconds,
  with a default of 30. Set `BORIS_STT_PARTIALS=0` to disable live partial decoding.
- Freeform trailing silence is now 700 ms. Confirmation trailing silence stays at 250 ms.
- Desktop modules are split by responsibility and documented in
  `desktop/docs/ARCHITECTURE.md`.
- `cargo xtask trace-report` has been removed. Per-turn traces remain in
  `~/.boris/traces/turns.jsonl`.
